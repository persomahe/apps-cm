Questions fréquentes

Les applications sont-elles gratuites ?

Oui, les applications sont conçues pour offrir une expérience simple et utile, avec un accès clair aux fonctionnalités essentielles.

Que faire si je rencontre un bug ?

Contactez-nous par e-mail avec une description du problème, l’appareil utilisé ainsi que les étapes pour le reproduire.

Est-ce que les données sont sécurisées ?

Nous mettons un point d’honneur à protéger les informations sensibles et à limiter l’accès à ce qui est strictement nécessaire.

Comment demander une fonctionnalité ?

Vous pouvez nous envoyer votre suggestion en indiquant précisément le besoin que vous souhaitez voir ajouté.
